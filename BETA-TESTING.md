# Pax Dei Atlas beta testing

[Download 0.91 Beta for Windows x64](https://github.com/jayfunkdown/pax-dei-atlas-downloads/releases/download/v0.9.1/Pax-Dei-Atlas-Setup-0.9.1-x64.exe) · [Discord](https://discord.gg/YjJxCBbeJU)

1. Get your private beta access code from the project owner.
2. Download and run the official Setup file. It installs for your Windows account without administrator access.
3. Launch Atlas and enter the code. No email is requested. Valid saved access is remembered.
4. Log into Pax Dei, match the game's UI-size preset in Atlas settings, then open the in-game map with your player arrow visible to establish position.
5. Enable and size the minimap as desired. Try filters, favourites, flags, route tracing and named encounters. Test party tools with another tester using a separate party room code.

An internet connection is required to activate and validate access. Beta codes normally expire after14 days unless the owner specifies otherwise. Keep access codes private. The beta installer is not Windows publisher-signed yet; Windows may show an unknown-publisher or reputation prompt. Only download from this repository's release links.

## Things to test

- Tracking while stationary, walking, sprinting, crossing area boundaries, opening the game map, closing chat and returning from menus.
- Named cards, crafted-item tiers, drum volume, reentering a POI and moving between nearby POIs.
- Main map/minimap size, zoom, filters and favourites; shared flags and peach route traces.
- Party travel and Roll/Pass, Ready and Wait tools.
- Dungeon entry, maps, enemy roster and exit recovery.

## Current limits

Tracking is approximate. Wrong corrections, drift or brief pauses can occur; reopening the game map with the player arrow visible can help recovery. Named locations show potential spawns, not live enemy presence. Dungeon entry uses a60-second/30m entrance heuristic and can trigger while waiting outside. There is no indoor position tracking; dungeon mode currently depends on the Named toggle.

## Send feedback

Use the Discord bug-reports, feature-requests or feedback channels, or [GitHub Issues](https://github.com/jayfunkdown/pax-dei-atlas-downloads/issues). Include Atlas version, Windows resolution and display scale, game UI-size preset, expected behavior, actual behavior and reproduction steps. For tracking problems show the compass/game map and Atlas where possible. Remove access codes, private room codes and unrelated personal chat.

## Updating

Use Settings > Updates. If a newer beta is available, Update now downloads and verifies it, closes Atlas, installs into the same folder and reopens. Settings and valid saved access are retained. You can also close Atlas and run a newer official Setup manually.
