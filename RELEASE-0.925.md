# Pax Dei Atlas 0.925 Beta — hotfix

19 October 2026

## Fixes and adjustments

- Drag the map divider all the way up beneath the toolbar to completely fold away the main map and its footer. Drag it down to reopen, or double-click to reset. The collapsed position is saved. This frees up the Party, Relic Search and Market panel on smaller screens, including 1280×720.
- Required-update download progress no longer repeatedly restores the main window. You can minimize it while the download continues, then restore it normally.
- Added tooltips to Filters, Settings and Minimap On/Off in the main window.
- Market and Relic Search no longer fill the main map with every result when first opened. Typing filters the list and displays matching locations. Clearing the search removes those result icons; saved pins and their chosen routes remain.

## Install or update

**[Download the Windows installer](https://github.com/jayfunkdown/pax-dei-atlas-downloads/releases/download/v0.9.25/Pax-Dei-Atlas-Setup-0.9.25-x64.exe)**

Existing testers: use the update offered in Atlas, or close Atlas and run the installer over your existing installation. Saved settings and valid beta access are intended to carry over. First-time testers: run the installer, open Atlas and enter your individually supplied beta access code. Codes remain valid until access is revoked. Never post your code in Discord.

Windows 10/11, 64-bit. Use the official link above. This beta installer is not Windows publisher-signed; update metadata is signed.

## Beta testing notes

Tracking remains approximate. A reported Aven-to-Wildlands border delay is under investigation and is **not claimed fixed in this hotfix**. Opening the in-game map with your player arrow visible can help confirm your position. Market data is an hourly snapshot and listings may have sold.

Please report problems with the version, what happened, and a cropped screenshot in the Atlas Discord bug-reports channel. Do not share access codes or private room codes.
