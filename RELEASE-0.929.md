# Pax Dei Atlas 0.929 Beta

31 October 2026

A data-only beta update for invited Windows 10/11 x64 testers. Lyonesse wider encounter areas no longer include Wolf Elder, and Residual Collector is no longer a named card.

[Download the Windows installer](https://github.com/jayfunkdown/pax-dei-atlas-downloads/releases/download/v0.9.29/Pax-Dei-Atlas-Setup-0.9.29-x64.exe) · [Tester instructions](https://github.com/jayfunkdown/pax-dei-atlas-downloads/blob/main/BETA-TESTING.md)

## Install or update

Existing testers: use **Settings → Updates**, or close Atlas and run the official Setup over your existing installation. No uninstall is needed. Saved access, settings, pins and watches are retained. This is a required pre-1.0 beta update when offered through the beta updater. The signed beta feed is already live.

New testers: run Setup and enter your privately supplied beta access code. Log into Pax Dei and open the game map with your player arrow visible to establish position. Keep codes private. Discord is optional for downloading and using Atlas. This beta installer is not Windows publisher-signed; use the official download above.

## Named encounters

- Wolf Elder stays as four standalone Lyonesse pins. It is no longer included in the two wider Lyonesse named encounter areas.
- Residual Collector is no longer a named card. Ordinary map spawn markers for it are unchanged.

## Known beta limits and feedback

Tracking behavior is unchanged from 0.928. Tracking remains approximate. Some roads are not mapped yet, so auto-path can leave the road where the map has no road data, and road forks are still being tuned. Horse speeds and mount detection are calibrated from limited live testing; other resolutions and UI scales may need more work. If tracking stalls, opening the game map with a clear player arrow remains a manual recovery option. There is no indoor position tracking.

Market data updates hourly and may include sold stock. Named encounters indicate possible spawns, not live presence. For bugs, include the time, Atlas version, whether you were on foot or riding, whether you used Y auto-path, the road or junction involved, and whether M corrected it. Remove access codes, private room codes and unrelated chat from screenshots.
